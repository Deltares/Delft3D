# How to generate debug output
All source/sink data communicated via preCICE or DIMR ends up in the source_sinks administration of D-Flow FM. To write this administration to file:   
Compare file "src\engines_gpl\dflowfm\packages\dflowfm_kernel\src\dflowfm_kernel\compute\advec.f90" in the D-Flow FM source code with the variant next to this readme.md file.   
Copy/paste into the source code:
- The `write(44`-block around line 330
- Some declarations, needed to get it compiled:  
      `use m_source_sink, only: source_sink_all_discharges`   
      `use m_transportdata, only: numconst`   
      `use m_flowtimes, only: time1`   
      `integer :: iconst`   
- Compile the code
- Run D-Flow FM coupled to C-SUMO (via DIMR or preCICE)   
  File `fort.44` will be created next to the mdu-file
- Compare `fort.44` files generated by different runs
