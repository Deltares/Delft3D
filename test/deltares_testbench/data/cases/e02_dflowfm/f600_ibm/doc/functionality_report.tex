\section{D-Flow FM immersed-boundary method}
This functionality group contains deterministic verification inputs for the Cartesian immersed-boundary method. It covers aligned and oblique channels, an annular channel, a lake at rest, and wind-driven closed basins. The input and documentation directories are versioned with DVC. Reference outputs and TestBench configuration entries are added after acceptance.
